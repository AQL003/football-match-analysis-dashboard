# ⚽ Football Match Analysis Dashboard

Interactive football match analysis dashboard built with **Streamlit** using  
**StatsBomb Open Data**.

## 📊 Features

### Match Overview
- Match summary
- Starting XI (home & away)
- Substitution timeline (vertical, Wyscout-style)
- xG Timeline

### Team Tactical Analysis
- Shot map
- Pass network
- Ball losses map
- Ball recoveries map
- Defensive block classification (low / mid / high)

### Player Analysis
- Player stats
- Pass map
- Heatmap
